# 斜率截距比作为"是否考虑收缩"的统一判据

这一节是给论文**问题四之后**准备的收口讨论：把问题一至三"固定半径"的假设
与问题四的动边界模型用同一个判据串起来，让三问对收缩的处理互相呼应，
而不是各说各话。**本文件夹是独立的，没有改动 `论文/` 下的任何文件。**

## 一句话结论

由干基含水率的定义可把体密度经验式写成

```
v(C) = V/m_d = (1 + C) / (a + bC) = (1/a) · (1 + C) / (1 + rC),    r = b/a
```

于是 "要不要考虑收缩" 等价于 "斜率截距比 r 是否等于 1"：

| 判据 | 含义 |
| --- | --- |
| `r = 1` | `v` 为常数 ⟺ `ρ_d` 为常数 ⟺ 干燥全程体积不变（无收缩） |
| `r < 1` | 隐含收缩；`r` 越小收缩越强，`a = ρ(0)` 只提供尺度 |

题面两式为 `r₃ = 128/650 = 0.197`、`r₄ = 90/760 = 0.118`，都远离 1。
也就是说，**"要考虑收缩"是题面系数本身给出的结论，不需要额外的物理假设**；
反过来，"斜率 = 截距"会在 `C₀ = 2.55` 处给出 `2307.5 kg/m³`，物理上不可能。

## 三个能直接写进论文的结果

1. **总量互证。** 由 `r₄` 反推的绝干半径 `1.211 cm`，与附件 2 实测终半径
   `1.198 cm` 相差 `1.1%`；换算成收缩系数是 `β = 0.891` 对 `0.922`（差 `3.4%`）。
   这解释了问题四为什么把附录 4 的物性配附件 2 的几何——题面两组数据本身互相印证。

2. **误差分级（三问呼应）。** 把各问结束时刻的水分场按体积加权平均再代入上式：

   | 问题 | 时刻 | 体积平均 `C̄` | 隐含径向线收缩 |
   | --- | --- | --- | --- |
   | 问题一 | 1800 s | 2.253 | **2.4%** |
   | 问题二 | 3 h | 1.364 | **11.2%** |
   | 问题三 | 57.42 h | 0.120 | **32.0%** |

   这既解释了问题一、二、三为什么可以取固定半径（问题一误差不足 3%），
   也解释了问题四为什么必须引入动边界（问题三结束已达三成），
   更把"忽略收缩"从一句定性假设变成带数字说明的近似。

   附件 2 的收缩有 50% 发生在 2.5 h 内、90% 在 10 h 内、99% 在 22 h 内，
   即收缩高度前置；而 `ρ` 律要求收缩与含水率同步下降，两者在同一含水率下的
   比体积相差 **10.6%~22.4%**——总量一致、路径不同。

3. **门槛表。** 线收缩达到 `3% / 5% / 10% / 20%` 分别对应
   `C ≈ 2.18 / 1.95 / 1.47 / 0.73`（附录 3）——可直接用来判断任意时间窗
   内能不能忽略收缩。

## 并入前建议一并处理的三处口径问题（本节未改正文）

这三处是本次核算中发现的正文内部不一致，**不属于本节内容**，但同一篇论文里
对同一个量给两套数字会被评阅人追，建议一并改：

1. **各向同性 vs 径向等长。** §6 的表 `tab:geo-shrink` 与图 `d29` 用
   **各向同性**口径（附录 4 在 `C=0.15` 得 `R=1.491 cm`，与附件 2 实测差
   `19.5%`）；而问题四的几何是**长度不变、只缩半径**，同一事应为
   `R=1.288 cm`（差 `7.0%`），绝干外推则是 `1.211 cm`（差 `1.1%`）。
   本节统一用后者。建议全文二选一——选径向会让"题目自洽"的结论更强。
2. **干物质守恒检验的三个数字不一致。** 正文表 `tab:drymass` 报
   `−25% / −13% / −26%`，同一张图的 caption 写"稳定在 −7% 附近"，
   而按 `result4_data.npz` 复算（固定物理位置网格 + 当前半径截断）为
   `−27% / −13.8% / −10.9%`。建议统一口径后重算一次。
3. **措辞。** 摘要与 §6 结尾现为"题面两组给定数据之间的固有张力""并不同源"。
   按本节的核算，更准确也更安全的说法是 **"总量互证（1%~3%）、路径互补
   （10.6%~22.4%）"**——两组数据分别刻画了平衡态比体积关系与实际干燥历程，
   路径不同是预期的，不是题目矛盾。
4. **一个末位数字。** §6 的表 `tab:beta` 与摘要把附录 3 的端点收缩系数写作
   `0.823`，精确值为 `522000/634660 = 0.822488`，三位小数应是 **`0.822`**。
   本节按精确值取 `0.822`；`check_consistency.py` 会校验这一位。
