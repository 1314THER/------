## 二、`solve_p1.py` 逐段解读

### 2.1 常量区（第 81–120 行）

```python
RHO    = 820.0        # kg/m^3
CP     = 2600.0       # J/(kg·K)
K_COND = 0.36         # W/(m·K)
H_HEAT = 25.0         # W/(m^2·K)
H_MASS = 8.0e-7       # m/s
RADIUS = 0.02         # m   ← 题面给的是 2 cm
LENGTH = 0.25         # m   ← 题面给的是 25 cm
```

这些行在做同一件事：**把题面的量全部换算成 SI 基本单位**。题面用 cm，而附录 2
的 $k$、$h$ 是 W/(m·K) 体系、$D$ 是 m²/s。如果在代码里混用 cm，像 $Dt/R^2$
这样的无量纲组合会差 $10^4$，这是本题最容易翻车的地方。

**规则：程序内部一律用 m / s / °C / kg，只在最终输出时换回 cm。**

```python
ALPHA = K_COND / (RHO * CP)     # 热扩散率 1.689e-7 m²/s
```

这个量不参与方程求解（方程里只用到 $k/(\rho c_p)$ 这个组合），但打印出来可以
立刻和 $D$ 对比：两者相差 34 倍，这正是"30 min 内热量铺满截面、水分只在表层动"
的根源。

```python
REPORT_TIMES  = [100, 300, 600, 900, 1200, 1500, 1800]
REPORT_POS_CM = [0.0, 0.5, 1.0, 1.5, 2.0]
```

这两个列表只影响**输出**，不影响计算——它们决定最后打印哪几行、哪几列。

### 2.2 `diffusion_coefficient`（第 126–149 行）

```python
return 7.0e-9 * np.exp(-0.89 / np.maximum(c, 1e-12))
```

逐个看：`7.0e-9` 是前因子，`np.exp(-0.89/C)` 是指数项，`np.maximum(c, 1e-12)`
是**防除零**——Picard 迭代的中间步可能出现 $C\le 0$，不保护会得到 `inf` 并污染
整个场。本题 $C\in[0.05,2.55]$，这个保护实际不会触发。

指数带负号意味着**含水率越低扩散越慢**：$C$ 从 2.55 降到 0.15 时，$D$ 从
$4.94\times10^{-9}$ 掉到 $1.86\times10^{-11}$，跨两个数量级。这既是水分方程
非线性的来源，也是必须用隐式格式（后向 Euler）而不是显式格式的原因。

### 2.3 `cell_weights`（第 156–195 行）★ 最容易写错的函数

```python
r = np.arange(n_fine + 1) * hx        # 节点坐标 r_i = i·hx
w = r * hx                            # 先按内部节点公式填满
w[0] = hx * hx / 8.0                  # 中心控制体的正确权重
w[n_fine] = hx * (RADIUS - hx / 4.0) / 2.0   # 表面控制体的正确权重
```

**为什么要权重？** 体积微元是 $\mathrm{d}V=2\pi L\,r\,\mathrm{d}r$，所以任意量的
体积分是

$$\int f\,\mathrm{d}V=2\pi L\int f\,r\,\mathrm{d}r\approx2\pi L\sum_i f_i\underbrace{\int_{CV_i}r\,\mathrm{d}r}_{w_i}$$

即 $w_i$ 就是第 $i$ 个控制体的 $\int r\,\mathrm{d}r$。

**为什么两端要单独改？**

| 节点 | 控制体范围 | $\int_{CV}r\,\mathrm{d}r$ |
| --- | --- | --- |
| 内部 | $[r_i-\frac{h_x}{2},\,r_i+\frac{h_x}{2}]$ | $r_ih_x$ |
| 中心 $i=0$ | $[0,\frac{h_x}{2}]$（左半边由对称性不存在） | $\frac{h_x^2}{8}$ |
| 表面 $i=N$ | $[R-\frac{h_x}{2},\,R]$ | $\frac{h_x(R-h_x/4)}{2}$ |

若偷懒用统一的 $w_i=r_ih_x$：中心权重会被算成 $r_0h_x=0$（容量为零），表面权重
接近两倍。两者叠加会让守恒检验凭空出现**约 1% 的残差**，把真正的数值问题掩盖掉。
论文里"守恒残差 $6.8\times10^{-14}$"这个数字，前提就是这里写对了。

**这里没有做任何平滑、去噪或异常值处理**——读进来是什么就是什么。时间推进时

### 2.5 `thomas`（第 231–280 行）

```python
cp[0] = upper[0] / diag[0]
dp[0] = rhs[0] / diag[0]
for i in range(1, n):
    m = diag[i] - lower[i] * cp[i - 1]
    cp[i] = upper[i] / m
    dp[i] = (rhs[i] - lower[i] * dp[i - 1]) / m
```

这是**前向消元**：把三对角方程组化为上三角。`cp`、`dp` 存的是"消元后的上对角
元素除以主对角元素"和"右端项除以主对角元素"——都是比值，不是原值。

```python
x[-1] = dp[-1]
for i in range(n - 2, -1, -1):
    x[i] = dp[i] - cp[i] * x[i + 1]
```

这是**回代**：从最后一个未知量往前逐一求出。

为什么不直接调用 `np.linalg.solve`？每个时间步要解两次三对角系统（水分还要
迭代若干次），$N=400$、1800 步合计上万次。追赶法是 $O(N)$，通用求逆是
$O(N^3)$，差几个数量级；而且追赶法不构造矩阵，内存也省。

### 2.6 `step_temperature`（第 287–369 行）★ 离散格式的来历

对照公式读这一段最有效。推导分四步。

**第一步：把 PDE 在控制体上积分。** 对
$\rho c_p\,\partial_tT=\frac1r\partial_r(k\,r\,\partial_rT)$ 两边乘
$r\,\mathrm{d}r$ 并在第 $i$ 个控制体上积分：

$$\rho c_pw_i\frac{\partial T_i}{\partial t}=k\,r_{i+1/2}\frac{T_{i+1}-T_i}{h_x}-k\,r_{i-1/2}\frac{T_i-T_{i-1}}{h_x}$$

**第二步：时间用后向 Euler。** 左端取新时刻，两边同除以 $\rho c_ph_x$，记
$a_t=\dfrac{k\,\Delta t}{\rho c_ph_x^2}$，得

$$r_iT_i^{n+1}+a_tr_{i-1/2}\left(T_i^{n+1}-T_{i-1}^{n+1}\right)+a_tr_{i+1/2}\left(T_i^{n+1}-T_{i+1}^{n+1}\right)=r_iT_i^{n}$$

对应代码第 335–341 行：

```python
for i in range(1, n):
    lower[i] = -a_t * rf[i - 1]                    # 左邻居系数 -a_t·r_{i-1/2}
    upper[i] = -a_t * rf[i]                        # 右邻居系数 -a_t·r_{i+1/2}
    diag[i]  = r[i] + a_t * (rf[i - 1] + rf[i])    # 自身系数
    rhs[i]   = r[i] * temp[i]                      # 右端只含旧时刻
```

（`rf` 就是界面坐标 $r_{i+1/2}=(i+0.5)h_x$。）

**第三步：中心节点 $r=0$。** 方程在 $r=0$ 有 $1/r$ 奇点，用洛必达法则取极限得
$\frac1r\partial_r(kr\partial_rT)\to2k\partial_r^2T$。离散上更直接：中心控制体只有
一个外界面 $r_{1/2}=h_x/2$，

$$\rho c_p\frac{h_x^2}{8}\frac{\Delta T}{\Delta t}=k\frac{h_x}{2}\cdot\frac{T_1-T_0}{h_x}\quad\Longrightarrow\quad\Delta T=4a_t(T_1-T_0)$$

```python
diag[0]  = 1.0 + 4.0 * a_t
upper[0] = -4.0 * a_t
rhs[0]   = temp[0]
```

**这三行就是"中心对称边界 $\partial T/\partial r=0$"的离散实现。** 它绝对不能写成
Dirichlet（把 $T_0$ 固定成某个值）——那相当于在中心放了一个恒温源，物理上完全错误。

**第四步：表面节点。** 控制体 $[R-h_x/2,R]$，外界面通量由第三类边界给出：

$$\rho c_pw_N\frac{\Delta T}{\Delta t}=-k\,r_{N-1/2}\frac{T_N-T_{N-1}}{h_x}+R\,h\,(T_\infty-T_N)$$

引入 $g_t=\dfrac{\Delta t}{\rho c_ph_x(R-h_x/4)}$（因为 $w_N=\frac{h_x(R-h_x/4)}{2}$，
所以 $\frac{\Delta t}{\rho c_pw_N}=2g_t$），再记对流项系数
$p_t=2g_tRh$、内部导热项系数 $q_t=2g_t\left(R-\frac{h_x}{2}\right)\frac{k}{h_x}$：

```python
g_t = dt / (RHO * CP * hx * (RADIUS - hx / 4.0))
p_t = 2.0 * g_t * RADIUS * H_HEAT
q_t = 2.0 * g_t * (RADIUS - hx / 2.0) * K_COND / hx
lower[n] = -q_t
diag[n]  = 1.0 + p_t + q_t
rhs[n]   = temp[n] + p_t * t_inf
```

**边界值 $T_\infty^{n+1}$ 取的是新时刻**（主循环按 $t=(n+1)\Delta t$ 插值得到），
这是后向 Euler 格式的组成部分。若图省事用旧时刻，边界就变成显式处理，稳定性和
精度都会下降。

### 2.7 `step_moisture`（第 376–458 行）

结构与温度步几乎相同，**三处差别**：

1. 系数从 $k/(\rho c_p)$ 换成 $D$，即 `dtb = dt * d_face / (hx * hx)`；
2. 界面上用**面值**而不是节点值：
   `d_face = 0.5 * (d_node[:-1] + d_node[1:])`。
   这一条很关键：用节点值会让离散格式不自洽，粗网格下表面含水率有约 1.6% 的
   系统偏差，改成界面平均后降到 0.12%；
3. 需要迭代，因为 $D$ 依赖 $C$，方程非线性：

```python
c_new = conc.copy()                       # 迭代初值：先用本步开始的值
for _ in range(picard_max):
    d_node = diffusion_coefficient(c_new) # ← 用本轮解算 D
    ...
    solved = thomas(lower, diag, upper, rhs)
    if np.max(np.abs(solved - c_new)) < picard_tol:
        c_new = solved; break             # 收敛就停
    c_new = solved                        # 否则继续迭代
```

**另一处保险在第 390–391 行：**

```python
c_old = conc.copy()          # 本时间步开始时刻的值
...
rhs[i] = r[i] * c_old[i]     # 右端项只能用 c_old，绝不能用 c_new
```

右端必须始终固定在**时间步开始时刻**。若写成上一轮迭代的结果，每迭代一次就
相当于又推进了一个 $\Delta t$，解会"跑快"好几倍（论文 §7.4.2 专门强调过）。

### 2.8 `solve`（第 465–564 行）—— 主循环

```python
hx = RADIUS / n_fine
r  = np.arange(n_fine + 1) * hx            # 节点坐标
rf = (np.arange(n_fine) + 0.5) * hx        # 界面坐标

stride = n_fine // N_OUT
if stride * N_OUT != n_fine:
    raise ValueError("n_fine 必须是 N_OUT=%d 的整数倍" % N_OUT)
```

最后三行保证**输出节点是计算网格的子集**（$N=400$ 时 `stride=20`）。题目要求输出
$0,0.1,\dots,2.0$ cm，恰好命中网格点，所以输出时直接切片 `[::stride]` 即可，
不需要插值——少一次插值就少一份误差。

时间推进（第 527–557 行）：

```python
for step in range(1, n_steps + 1):
    t_now = step * dt
    t_inf = float(np.interp(t_now, t_air, temp_air))   # 查烘房工况
    c_inf = float(np.interp(t_now, t_air, humid_air))

    conc = step_moisture(conc, c_inf, dt, hx, r, rf, picard_max, picard_tol)
    temp = step_temperature(temp, t_inf, dt, hx, r, rf)
```

**两行先后各推进一次就够了**——这是问题一的特殊性质：$D$ 不依赖 $T$、其余物性不

其余几行都是记录：把新场抽稀存进历史数组、记录表面瞬时通量、更新守恒累积量。

### 2.9 `conservation_report`（第 571–606 行）

```python
removed    = q[0] - q[-1]                          # 内部存量减少
cumulative = area * dt * np.sum(surf_flux[1:])     # 表面累计流出
relative_residual = (removed - cumulative) / removed
```

检验的是最朴素的物理事实：**内部水量的减少必须等于表面流出的水量**。因为是有限
体积离散，这个恒等式在离散意义下**严格成立**，残差只应是舍入误差（实测
$6.8\times10^{-14}$）。如果这里跑出 1% 量级的残差，说明格式写错了——最常见的就是
`cell_weights` 或下面这个求和方式。

```python
cumulative = area * res["dt"] * float(np.sum(res["surf_flux"][1:]))
```

用的是**左矩形和**（通量取新时刻），并且 `[1:]` 跳过初始时刻。改成梯形法看似更
"精确"，反而会引入 $O(\Delta t)$ 的**假残差**——因为离散恒等式对应的就是左矩形和，
换求和方式就不再是同一个恒等式。

函数还额外报告 $W=\int\rho_dC\,\mathrm{d}V$（真实水量）。$W$ 不守恒是"密度口径
近似"的直接后果，论文里作为建模选择的不确定性如实披露，而非掩盖。

## 三、`solve_p234.py` 逐段解读（只讲与问题一不同之处）

### 3.1 物性函数（第 110–163 行）

```python
def props_p23(conc, temp):
    c    = np.maximum(conc, 1e-12)
    t_k  = temp + 273.15                 # ← °C → K
    rho  = 650.0 + 128.0 * c
    drho = np.full_like(c, 128.0)        # ← dρ/dC，链式法则要用
    cp   = 1450.0 + 2736.0 * c / (c + 1.0)
    k    = 0.21 + 0.38 * c / (c + 1.0)
    d    = 2.4e-3 * np.exp(-0.45 / c) * np.exp(-3850.0 / t_k)
    return rho, drho, cp, k, d
```

两处必须留意：

* **`t_k = temp + 273.15`**：$D$ 里的 Arrhenius 项 $e^{-3850/T}$ 要求绝对温标。
  误用摄氏度会让 $D$ 差几个数量级——本题最典型的单位坑。
* **`drho`**：问题四的水分方程左端是 $\partial(\rho C)/\partial t$，
  按链式法则展开为 $(\rho+C\rho')\partial C/\partial t$，故要 $\rho'$；
  `p23_variants.py` 的"变密度口径"里也用到它。问题二、三的水分方程用
  经典 Fick 形式（$\rho$ 不进入水分方程），不需要 $\rho'$。
  $c_p$、$k$ 写成 $C/(C+1)$ 的形式是附录给的，照抄即可。

### 3.2 `air_conditions`（第 191–209 行）

```python
temp = np.where(tq <= T_PREHEAT_END, np.interp(tq, _AIR_T, _AIR_TEMP), T_CONST)
```

### 3.3 `Pchip` 类（第 216–300 行）

问题四的 $R(t)$ 直接进入度量因子与表面边界条件（并用于反演收缩速率 $\dot R$），
三种做法的取舍：

| 做法 | 问题 |
| --- | --- |
| 差分 | 把噪声放大 $1/\Delta t$ 倍（本题信噪比仅约 2:1，见论文 §5.4） |
| 分段线性 | $\dot R$ 在节点处跳变，等于把间断喂进方程 |
| **PCHIP** | $C^1$ 连续 + 保单调 + 无过冲 ✔ |

构造的核心在**节点导数 $m_i$ 的取法**（第 240–256 行）：

```python
if delta[i - 1] * delta[i] <= 0.0:
    m[i] = 0.0                                     # 极值点 → 压平，防过冲
else:
    w1 = 2.0 * self.h[i] + self.h[i - 1]
    w2 = self.h[i] + 2.0 * self.h[i - 1]
    m[i] = (w1 + w2) / (w1 / delta[i - 1] + w2 / delta[i])   # 加权调和平均
```

**用加权调和平均而不是算术平均，正是"不过冲"的关键**——这是 Fritsch–Carlson
构造的精髓。有了节点值和节点导数，区间内用标准三次 Hermite 基函数求值
（`__call__`），求导则对同一表达式解析求导（`deriv`），因此 $\dot R$ 是精确的
解析导数，不是差分。

### 3.4 `_assemble`（第 329–386 行）★ 两个方程共用的组装器

问题二以后两个方程结构完全相同、只是系数不同，于是抽出一个组装函数，
参数是 `(lam, face, value, alpha_const, far_value, n)`：

| 参数 | 含义 | 温度方程取 | 水分方程取 |
| --- | --- | --- | --- |
| `lam` | 时间导数项系数 | $\rho c_pwR^2$ | $wR^2$ |
| `face` | 界面扩散系数 | $\Delta t\,k_{\text{face}}\xi_{\text{face}}/h$ | $\Delta t\,D_{\text{face}}\xi_{\text{face}}/h$ |
| `alpha_const` | 表面第三类边界 | $\Delta t\,Rh$ | $\Delta t\,Rh_m$（四个问题同口径） |
| `far_value` | 远场值 | $T_\infty$ | $C_\infty$ |

三段组装（第 356–385 行）：

```python
# 中心：没有左邻居（对称性已含在 weight[0] 里）
diag[0] = lam[0] + face[0]
upper[0] = -face[0]
rhs[0] = lam[0] * value[0]

# 内部：左界面 -face[i-1]，右界面 -face[i]
lower[i] = -bm
diag[i]  = lam[i] + bm + bp
upper[i] = -bp

# 表面：第三类边界
beta = face[n - 1]
lower[n] = -beta
diag[n]  = lam[n] + alpha_const + beta
rhs[n]   = lam[n] * value[n] + alpha_const * far_value
```

**为什么没有对流项？** 这是问题四最容易写错的一步。贴体坐标下时间导数满足
$\partial_t|_r=\partial_t|_\xi-(\xi\dot R/R)\partial_\xi$，而物理坐标下的方程
本身含骨架对流 $u\partial_r$，其中 $u=\xi\dot R$ 是材料点速度，于是
$u\partial_r=(\xi\dot R/R)\partial_\xi$ 与坐标变换项**精确抵消**：
$\mathrm{D}/\mathrm{D}t=\partial_t|_\xi$。也就是说 $\xi$ 就是材料坐标，
方程里不该再有"挤压"项，只有度量因子 $1/R^2$ 与边界条件里的 $R$ 随收缩变化。

### 3.5 `solve`（第 393–540 行）—— 与问题一的三处关键差别

**差别 1：网格建在贴体坐标上。**

```python
h = 1.0 / n                     # ξ∈[0,1]，所以步长本身无量纲
xi = np.arange(n + 1) * h
weight = xi * h                 # 权重是 ∫ξ dξ，不再是 ∫r dr
weight[0] = h * h / 8.0
weight[n] = h * (1.0 - h / 4.0) / 2.0
```

**差别 2：两方程互相迭代，而不是先后各推一次。**

```python
for _ in range(picard):
    rho, drho, cp, k_cond, diff = props(conc, temp)   # ← 用当前 C 和 T 算物性
    ...
    conc_new = thomas(...)      # 先解水分
    ...
    temp_new = thomas(...)      # 再用新的水分场解温度
    change = max(|Δconc|, |Δtemp|)
    if change < picard_tol:
        break
```

这就是"耦合"在代码里的样子：$D$ 依赖 $T$、$\rho,c_p,k$ 依赖 $C$，
每轮都要用对方的最新值重算物性。

**差别 3：时间步开始时刻的状态被冻结。**

```python
conc_old = conc.copy()
temp_old = temp.copy()
```

之后所有 `rhs` 都引用 `conc_old`／`temp_old`。这是 Picard 迭代最容易写错的地方，
用上一轮迭代值会让解"跑快"，第 470–472 行的注释专门标了这一点。

**烘干判据（第 519–524 行）：**

```python
if conc[0] < C_DRY:          # C_DRY = 0.15
    dry_step = step
    break
```

只检查中心的 `conc[0]`。依据是：水分由表及里脱除，中心含水率全程最高，
所以"各处达标"等价于"中心达标"，判据可以从"全场取最大"简化成看一个数，
且不影响结论。

## 五、`p23_variants.py`：网格 / 时间步 / 口径三因素对照

这个脚本只干一件事：把问题三的烘干时长对"径向网格数 $N$"、"时间步长
$\Delta t$"、"水分方程口径"三个因素的依赖逐一分离开来，对应论文第 9、10 节
（表 14、表 15）。它**不重新实现离散格式**，而是 `import solve_p234 as base`
后复用物性、空气条件、`_assemble` 与 `thomas`——这样对照实验与论文主结果
同源，唯一变化的量就是被测的那个因素。

两种口径在代码里只差三行：

| | 本文口径（`form="fick"`） | 变密度对照（`form="cons"`） |
| --- | --- | --- |
| 累计项系数 | `accum = 1` | `accum = rho + conc*drho` |
| 界面通量系数 | `mass_face = D_face` | `mass_face = rho_face * D_face` |
| 表面对流系数 | `alpha = dt*R*hm` | `alpha = dt*accum[n]*R*hm` |

温度方程两块完全相同，所以两者之差纯粹来自水分方程。

```bash

# 单组
$PY 代码/p23_variants.py --n 200 --dt 5 --form cons

# 复现论文表 14 与表 15（20 组，6 进程并行，约 5 分钟）
$PY 代码/p23_variants.py --table --jobs 6 --csv 输出/问题三-网格与口径对照.csv
```

自检时应当看到：网格加密使烘干时长**单调增加**（$N=20\to400$ 为
216215 → 219830 s，增量 2360/765/345/145 逐次减半），
时间步放宽使烘干时长**单调变大但幅度小一个数量级**
（$\Delta t=2\to120$ s 只从 219328 增到 219720 s），
而两种口径的相对差在全部 20 组参数下稳定在 $5.9\%$。
三条趋势如果对不上，说明改动破坏了格式的一致性。

> 注意"报告网格"与"求解网格"的区别：题目要求按 0.1\,cm 输出，
> 但直接以 $N=20$ 求解会因表面控制体只有 $h/2$ 厚而偏低 1.6\%。
> 正确做法是在 $N=200$ 上求解，再把结果插值到 0.1\,cm 的报告网格。

## 六、常见疑问速查

| 疑问 | 答案 |
| --- | --- |
| 为什么不用 `scipy.solve_ivp` 或 `pdepe`？ | 本题是变系数非线性抛物型方程，还要处理动边界；自己写有限体积能保证离散守恒，且便于做守恒/收敛检验 |
| 为什么时间步不用 Crank–Nicolson？ | 后向 Euler 无条件稳定且实现简单；实测 $\Delta t=5$\,s 与 $2$\,s 的烘干时长只差 12\,s，二阶格式带来的收益为零 |
| 为什么水分方程要迭代而温度方程不用？ | 温度方程关于 $T$ 是线性的（物性用上一轮的值）；水分方程里 $D(C)$ 出现在系数中，必须迭代 |
| 为什么输出要保留 NaN／空单元格？ | 收缩后超出半径的位置**没有定义**，填 0 或外推都是编造数据 |
| 想让结果更准该调什么？ | 不建议盲目加密网格。真正的大头是 $D$ 的经验式与水分方程口径（$\pm15\%\sim22\%$），网格误差不足 0.2%（见论文表 17） |
